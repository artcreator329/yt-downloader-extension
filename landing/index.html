Help

Questions & quick fixes

Stuck on a step? The answer is probably here.

FIX“Manifest file is missing or unreadable”
You selected the ZIP file or the wrong folder. Unzip first, then in Load unpacked pick the folder that directly contains manifest.json. Sometimes unzipping creates a folder inside a folder — choose the inner one.
FIXI can't find the “Load unpacked” button
It only appears after Developer mode is switched on (top-right of the extensions page). Once it's on, the button shows up in the top-left.
FIXThe popup doesn't show my video
Refresh the YouTube tab after installing (tabs opened before setup don't know about the extension yet), then open the popup again. You can always paste the video's link into the popup and click Load. Also check the extension's switch is on at the extensions page.
FIXIt stopped working after I moved or deleted the folder
The browser loads the extension from that folder every time. Put the folder back (or download again), then click Load unpacked once more.
FIX“YouTube is asking for a sign-in check”
YouTube wants proof you're a real viewer. Open the extension popup, turn on Use my YouTube session, click Allow, and make sure you're signed in to YouTube in this browser. Then try again. See “If YouTube asks” in the how-to for exactly what this shares.
FIXMy browser asks “What do you want to do with this file?”
Click Save and the file goes to your Downloads folder. To stop the question for good: in Microsoft Edge, open Settings → Downloads and turn off Ask me what to do with each download. In Chrome, open Settings → Downloads and turn off Ask where to save each file before downloading.
FIXIt's stuck on “Preparing…”
Preparing usually takes 10–30 seconds, and long videos can take a bit more. If it's been over a minute, close the popup, reopen it, and try again. A lower quality such as 720p is often quicker.
Why isn't this on the Chrome Web Store?
Google doesn't allow YouTube download tools on its store. Loading an extension through Developer mode is a built-in browser feature that lets you install it directly instead.
Will this get my Google account banned?
No. Developer mode is an official browser feature, and using it for personal extensions doesn't affect your Google account.
The browser shows a “Disable developer mode extensions” pop-up
Some browsers show this reminder on startup. Just close it (don't click Disable) and the extension keeps working.
Do I need to install any other software?
No. All the heavy lifting happens on our server, and finished files go straight to your browser's Downloads folder.
